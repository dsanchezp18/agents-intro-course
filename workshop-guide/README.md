# AI Agents Workshop Guide

This folder contains the English study guide and the source materials for **A Mostly Harmless Introduction to Claude Code, Codex, and Friends**, prepared from the local workshop recording.

## Contents

- `lesson.pdf`: compact seven-page study guide rendered with XeLaTeX.
- `lesson.qmd`: Quarto source with UTF-8 text, code examples, one-inch margins, and 1.5 line spacing.
- `lesson.tex`: generated LaTeX source.
- `transcript.cleaned.md`: cleaned transcript organized by time markers.
- `transcript.plain.txt`: flattened transcript.
- `meta.json`: recording and transcription metadata.
- `skill/SKILL.md`: the reusable skill used to fetch, clean, author, and render the lesson.

The full recording is retained in the owner's local Courses folder. It is not committed here because the file is approximately 343 MB, above GitHub's standard 100 MB per-file limit.
