# data/raw_zip

## Purpose
Original monthly ENEMDU zip downloads from INEC, kept as-is for provenance.
Not read directly by any script; see `data/raw/` for the extracted files.

## Contents
`enemdu_2025_01.zip` .. `enemdu_2025_12.zip`.

## Naming Convention
`enemdu_YYYY_MM.zip`, as downloaded from INEC.

## Dependencies
None (original source).
