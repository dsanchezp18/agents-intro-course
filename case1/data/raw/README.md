# data/raw

## Purpose
Extracted ENEMDU microdata (SPSS `.sav`), one subfolder per survey month.
Never modified after extraction.

## Contents
`2025_01/` .. `2025_12/`, each with `enemdu_persona_*.sav`,
`enemdu_vivienda_hogar_*.sav`, `enemdu_consumidor_*.sav` (and, for October
only, `enemdu_ambiental_2025_10.sav`).

## Naming Convention
Folder = `YYYY_MM`; files keep INEC's original names.

## Dependencies
Extracted from the corresponding zip in `data/raw_zip/`.
